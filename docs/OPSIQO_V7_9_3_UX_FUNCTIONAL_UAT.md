# OPSIQO 8.5 V7.9.3 — End-to-End UAT Matrix

The release should not be treated as complete merely because pages render.

## Navigation
- Employee: Home → My HR → Time & Leave → Learning → HR Help.
- Manager: Home → My Team → leave approvals → performance → recruiting where authorized.
- HR: Home → People → Recruiting → Onboarding → Time & Leave → Performance → Learning → Compensation.
- Admin: Settings/Admin & Platform → integrations/security/automation/audit.
- Search `leave`, `employee`, `recruiting`, `analytics`, `settings`; each result opens the intended page.
- Keyboard-only: Tab to Skip to main content, activate it, verify focus moves to main.

## Functional journeys
1. Sign in, register, forgot-password, invitation acceptance.
2. Create employee and verify directory/profile/assignment.
3. Employee self-service leave request → manager approval → resulting balance/status.
4. Requisition → candidate → ATS evidence → interview → human decision.
5. Onboarding case → tasks → acknowledgement/training.
6. Performance goal/review/check-in.
7. Learning assignment/completion/certificate.
8. Document upload/security scan/review/authorized download.
9. Universal import preview → validation → human confirmation.
10. Workflow/automation execution → progress → retry/reconciliation.
11. Analytics/report/export with empty, partial and populated data.
12. Offboarding/separation with consequential-action review.
13. Settings, appearance, profile, notifications, integrations.
14. Employee/manager permission isolation and forbidden-path behavior.
15. Mobile navigation and form completion at 360–430 px width.

## Required outcome
Every visible control must:
- complete its documented action, or
- clearly explain why it is unavailable/not permitted/not configured,
without silent failure.
