## TypeScript dependency-aware semantic gate
A full project `tsc --noEmit` was attempted with the globally available TypeScript compiler, but the release intentionally has no trusted installed dependency tree. v2.8-targeted diagnostics were limited to missing external/ambient dependency types (`next`, `react`, Node), JSX ambient-type cascades, and implicit-any cascades caused by those missing package declarations. After excluding those unavailable-dependency diagnostics, **no additional v2.8-specific diagnostic class remained**.

This is not a substitute for the mandatory dependency-aware production typecheck.

## Dependency/build gate
A bounded public-registry `npm install --package-lock-only --ignore-scripts` attempt did not complete within the execution environment and produced **no `package-lock.json` and no `node_modules` tree**. No partial dependency state is shipped.

Therefore v2.8 is **source/integration validated, not dependency-build verified in this environment**. Before production run:

```powershell
npm install --registry=https://registry.npmjs.org
npm run typecheck
npm test
npm run test:rules
npm run build
npm run strategy:review
npm run ai:evaluate
npm run ai:governance-check
npm run preflight:production
npm run uat:lifecycle
```

Keep and commit the generated `package-lock.json`; use `npm ci` thereafter.

## Decision boundary
The Strategy Center is a governed decision-support layer. Readiness scores, capability risk, scenario scores, risk-appetite exposure and benefits-realization metrics are operational indicators. They are not legal conclusions, financial forecasts, fiduciary determinations, Board assurance opinions, or authorization to execute hiring, layoffs, compensation, promotion, succession or other individual employment actions.
