# OPSIQO HCM v2.8 Production / Rollback Runbook

## Pre-production gates
1. Generate and commit a trusted `package-lock.json` from the approved npm registry.
2. Run `npm ci`, `npm run typecheck`, `npm test`, `npm run test:rules`, `npm run build`.
3. Run `npm run ai:evaluate`, `npm run ai:governance-check`, `npm run preflight:production`, `npm run uat:lifecycle`.
4. Confirm `/strategy` loads only for authorized roles and direct Firestore reads/writes fail for all v2.8 strategy collections.
5. Validate independent approval using separate creator/submitting reviewer and approver accounts.
6. Validate no scenario route has any recruiting, compensation, succession, separation or worker mutation path.

## Operations
```powershell
$env:OPSIQO_JOB_ORG_ID="YOUR_ORG_ID"
npm run strategy:review
```
Schedule according to organizational governance cadence. Review risk-appetite breaches and overdue strategic initiatives; the job creates operational notifications only.

## Rollback
Roll back the application artifact to the prior verified release. Do not delete strategy records. Preserve audit logs and server-only collections. Disable v2.8 navigation/permissions only through an approved rollback change.
