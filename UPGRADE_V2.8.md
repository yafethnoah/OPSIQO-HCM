# OPSIQO HCM v2.8 Upgrade

Adds Enterprise Human Capital Strategy, Board Workforce Governance & Strategic Scenario Center.

## Commands
```powershell
npm install --registry=https://registry.npmjs.org
npm run typecheck
npm test
npm run test:rules
npm run build
npm run strategy:review
npm run ai:evaluate
npm run ai:governance-check
npm run preflight:production
npm run uat:lifecycle
```

Strategic scenario outputs are planning evidence only. They do not authorize hiring, layoffs, compensation, promotion, succession, or other individual employment actions.
