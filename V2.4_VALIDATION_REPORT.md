## Regulatory source monitor hardening
- HTTPS is mandatory.
- Local/internal hostnames are rejected.
- Literal and DNS-resolved private/non-public addresses are rejected.
- IPv6 host brackets are normalized before IP evaluation.
- IPv4-mapped IPv6, loopback, unique-local, link-local, multicast, carrier-grade NAT, benchmark and documentation/non-public IPv4 ranges are blocked.
- Production requires an exact comma-separated public-host allowlist in `OPSIQO_REGULATORY_SOURCE_HOSTS`.
- `/api/health/ready` fails when the production regulatory-source allowlist is empty.
- Redirects are manually revalidated and capped.
- Responses are limited to supported text/JSON media types and 2 MB.
- Snapshots persist fingerprints/metadata rather than copied source-page content.
- Direct runtime boundary checks rejected HTTP, loopback/private IPv4, IPv6 loopback, IPv4-mapped IPv6, IPv6 link-local and localhost targets; production host allowlist rejection also passed.
- Direct runtime readiness check passed with a synthetic complete production configuration without exposing secret values, and failed closed when the regulatory-source allowlist was removed.

## Production network caveat
Application-layer URL validation is defense in depth, not a substitute for infrastructure egress controls. Production should restrict outbound traffic to the approved regulatory destinations because DNS/network behavior can change between application validation and the outbound connection.

## Dependency-aware build gate
A public-registry lockfile installation was attempted in this execution environment but did not complete within the available tool window and produced no trustworthy `package-lock.json` or dependency tree. Incomplete state was not retained.

Therefore the following remain mandatory before production promotion:

```powershell
npm install --registry=https://registry.npmjs.org
# Review and commit package-lock.json, then use npm ci thereafter.
npm run release:gate
npm run typecheck
npm test
npm run test:rules
npm run build
npm run ai:evaluate
npm run ai:governance-check
npm run preflight:production
npm run uat:lifecycle
npm run governance:review
npm run diagnostic:review
npm run regulatory:review
```

The release gate intentionally fails while `package-lock.json` is absent.
