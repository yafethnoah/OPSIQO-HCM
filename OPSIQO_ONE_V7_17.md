# OPSIQO ONE v7.17 — Accessibility Translation Portfolio Execution

OPSIQO ONE v7.17 is a certification-and-evidence phase built on v7.16. It adds four controlled capabilities without expanding the consequential AI execution surface:

1. **Program Portfolio Intelligence** — Project → Funding → Workforce → explicit budget/actual/commitment/forecast evidence with source references and currency separation.
2. **Reviewed Meeting → Workflow templates** — three templates convert reviewed creator-owned meeting actions into **disabled** manual workflows; activation remains a separate governed action.
3. **Browser-backed accessibility evidence** — a real Chromium/Chrome/Edge CDP smoke checks public authentication routes for semantics, accessible names, focus entry, target-size floor and 320px reflow.
4. **Translation inventory and coverage evidence** — the source inventory identifies remaining candidate English strings instead of falsely claiming that every inherited HCM screen is translated.

## Execute boundary

V7.17 deliberately does **not** add another Safe Self-Service Execute action. The only enabled allowlisted action remains the v7.16 operation that marks unread notifications explicitly targeted to the signed-in actor as read. Locale and appearance updates remain candidates held for UAT evidence.

Consequential employment, compensation, approval, personnel deletion, workflow activation, security and tenant-administration actions remain prohibited from generic AI execution.

## Program Portfolio truth model

- Financial values must be explicit governed evidence.
- Every evidence row has a source type and source reference.
- Project and funding-source relationships are server validated.
- Evidence dates must fall inside the project period.
- Evidence currency must match the funding source.
- Approved budget and forecast are latest-snapshot evidence.
- Actual and commitment evidence are additive.
- Currency totals are never silently converted or combined.
- Compensation records are not used as accounting actuals.
- Missing evidence is reported as missing/not configured rather than inferred.
- The portfolio does not determine donor allowability, legal compliance, audited financial statements or future funding certainty.

## Accessibility truth model

The browser smoke is real browser evidence, not a WCAG 2.2 AA conformance claim. Full certification still requires representative authenticated journeys, contrast testing, keyboard-only completion, zoom/reflow, screen-reader testing, language-of-parts review, error/validation testing and supported-browser/device review.

## Translation truth model

V7.17 adds source inventory and translated new OPSIQO ONE surfaces, but the inherited product still contains legacy strings requiring cataloguing and browser review. The inventory is intentionally evidence of remaining work, not a completeness percentage.
