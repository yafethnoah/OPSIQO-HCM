# OPSIQO ONE V7.21 — Document, Policy & Learning Knowledge

V7.21 is a stabilization/completion release. It does not broaden AI execution authority. It expands reviewed multilingual coverage, authenticated accessibility UAT, and the permission-scoped organizational Knowledge Graph/Organizational Memory using explicit governed policy, compliance, workflow, knowledge and learning records.

## Implemented

- Reviewed EN/FR/ES/AR exact-string coverage expands to Compliance/Documents, Policy Intelligence, Compliance Radar, Employee Experience, Employee Service Center and Workflows.
- Translation inventory now measures **635 exact reviewed source candidates across 15 governed surfaces**, with **3,160 heuristic candidates remaining** and **643 explicit catalog entries**.
- Authenticated browser accessibility matrix expands to **19 signed-in routes** and requires reviewed Arabic markers on the six new V7.21 surfaces.
- Knowledge Graph adds explicit, permission-scoped nodes for policies, knowledge articles, workflows, courses, learning paths and compliance requirements.
- Knowledge Graph adds explicit edges for policy audiences, compliance requirement references, course/skill mappings, learning-path course/position/skill targets and scoped worker/course assignments.
- Scenario Lab / Digital Twin and Intelligence Hub expose the new connected-knowledge counts.
- Organizational Memory can retrieve **published learning-course metadata** with canonical internal citations when `learning.read` is available.
- Existing policy, HR knowledge and workflow memory sources remain intact.
- Safe Execute remains frozen to `notifications.mark_visible_read` only.

## Governance boundaries

- New graph relationships are created only from explicit authoritative OPSIQO fields; keyword similarity does not create relationships.
- Policy/compliance graph evidence requires `policies.read` and/or `compliance.read` as appropriate.
- Knowledge articles require `service.read` or `experience.read`.
- Workflows require `workflow.read`.
- Learning graph/memory evidence requires `learning.read`.
- Employee-document contents, compensation, health, employee cases and private contact information remain excluded from the general Knowledge Graph/Organizational Memory layer.
- The graph does not infer legal applicability, funding eligibility, employee suitability, protected traits or employment outcomes.
- Published learning-course retrieval is internal organizational evidence, not proof that a worker completed a course.
- Reviewed translation coverage is not a claim that all legacy screens are linguistically complete.
- Browser accessibility tooling is implementation/UAT evidence, not a WCAG 2.2 AA conformance certificate.
- No new AI Execute capability is authorized in V7.21.
