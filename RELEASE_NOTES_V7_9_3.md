# OPSIQO HCM 8.5 V7.9.3 — UX + functional closure

V7.9.3 makes My OPSIQO the default entry point and simplifies navigation around Start, People, Talent & Work, Insights, More, and Admin & Platform. Advanced areas are collapsed by default, navigation is searchable and permission-aware, active pages expose `aria-current`, keyboard users receive a skip-to-main link, and static route-integrity checks prevent dead navigation destinations.

No existing HCM module is removed. The change reduces navigation burden while preserving the underlying governed services and RBAC boundaries.
