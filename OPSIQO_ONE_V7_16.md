# OPSIQO ONE v7.16 — Accessible Multilingual Program Execution

OPSIQO ONE v7.16 advances the Human + AI Operating System with five controlled capabilities:

1. **Program Workforce Intelligence** — explicit Project → Grant/Funding → Allocation → Worker → current Position/Org Unit → planned funded-cost evidence.
2. **Meeting → Workflow promotion** — reviewed, creator-owned meeting actions may be promoted into a **disabled** manual workflow; activation remains a separate audited action.
3. **Safe Self-Service Execute** — Ask OPSIQO gains one hard-coded low-risk execute action: mark unread notifications explicitly targeted to the signed-in actor as read through the authoritative notification service.
4. **Accessibility hardening + readiness evidence** — high contrast, strong focus, reduced motion, larger text, link visibility, route announcements and measurable WCAG 2.2 AA implementation evidence without a false conformance claim.
5. **Broader multilingual shell** — English, French, Spanish and Arabic shell/navigation/Ask OPSIQO support with Arabic RTL and evidence-preserving AI language instructions.

## Non-negotiable governance boundaries

- Normal Cortex agents retain Observe/Recommend/Prepare ceilings; no built-in agent receives broad Execute authority.
- The Safe Self-Service Executor accepts only the hard-coded notification-read action.
- Shared role notifications are not changed by the safe bulk action; only records explicitly targeted to the signed-in actor can be marked read.
- Consequential employment, compensation, approval, personnel deletion, workflow activation, security and tenant-administration decisions remain outside this Execute path.
- Program Workforce cost uses only the explicit `plannedAnnualAmount` entered on workforce funding allocations. It does not read restricted compensation records or infer salary.
- Meeting → Workflow promotion requires `workflow.manage`, creator ownership and reviewed status, and creates a disabled workflow.
- V7.16 does **not** claim WCAG 2.2 AA conformance. Manual keyboard, assistive-technology, contrast, zoom/reflow and authentication testing remain required.
- V7.16 does **not** claim every legacy module is fully translated. Translation coverage reports remaining legacy review explicitly.
